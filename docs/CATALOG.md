## Reference manuals

- [GNU Coreutils](https://www.gnu.org/software/coreutils/manual/coreutils.html): file operations, permissions, checksums, and text utilities.
- [GNU Bash](https://www.gnu.org/software/bash/manual/bash.html): current-shell variables, aliases, jobs, and redirection.
- [GNU Findutils](https://www.gnu.org/software/findutils/manual/html_mono/find.html): recursive file searches.
- [GNU Grep](https://www.gnu.org/software/grep/manual/grep.html), [Sed](https://www.gnu.org/software/sed/manual/sed.html), and [Gawk](https://www.gnu.org/software/gawk/manual/gawk.html): text searches and transformations.
- [GNU Tar](https://www.gnu.org/software/tar/manual/tar.html): archive creation and extraction.
- [curl manual](https://curl.se/docs/manpage.html): HTTP requests and downloads.
- [systemctl](https://www.freedesktop.org/software/systemd/man/latest/systemctl.html) and [journalctl](https://www.freedesktop.org/software/systemd/man/latest/journalctl.html): service and log operations.

## Usage notes

Templates containing angle brackets must be edited before execution. Read descriptions before copying. File operations assume you choose the correct terminal working directory. Entries tagged `current-shell` are copy-only because a new terminal cannot change the state of an existing shell. Optional tools such as ripgrep, htop, zip, and DNS utilities may require installation. Syntax checks do not establish that every tool or option exists on every Linux distribution.
